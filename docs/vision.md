# Portfolio Vision

Create a public portfolio that feels like a polished product experience, not a static resume.

## Outcome

The portfolio should help recruiters, engineering managers, and teams quickly understand Sergio's product engineering profile while also serving as a public frontend code sample.

## Audience

| Audience                       | What they need                                                                                                  |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------- |
| Recruiters                     | Clear role fit, contact links, and searchable career positioning.                                               |
| Engineering managers           | Evidence of judgment, ownership, frontend care, and systems thinking.                                           |
| Prospective frontend reviewers | A public page and repository that demonstrate semantic HTML, CSS, responsive design, and frontend fundamentals. |
| Sergio                         | A maintainable personal site that can evolve through documented decisions.                                      |

## Positioning

Senior Product Engineer focused on Ruby on Rails, SaaS, APIs, and full-stack web platforms.

## Experience Strategy

Most production work is private. The site should say that clearly and use the portfolio itself as the public implementation sample.

Sanitized career content can still show real experience through company names, roles, dates, themes, and verified outcomes.

## Experience Goals

- Minimalist and technical.
- Professional but not generic.
- Visual, graphic, and timeline-driven.
- Useful with JavaScript disabled.
- Strong in accessibility, SEO, and performance.
- Transparent about AI-assisted workflow.

## Non-Goals

- Do not build a fake product case study.
- Do not expose private client or repository information.
- Do not depend on JavaScript for core navigation or content.
- Do not add a real AI API in the MVP.
