# Mockup Critic

Use this skill before implementation starts for any screen or major section.

## Review Priorities

- Mockups are references, not production assets.
- A beautiful mockup is not acceptable if it cannot become semantic, accessible HTML.
- Every approved mockup needs desktop and mobile consideration.
- Text in AI-generated images must be treated as placeholder until rewritten manually.
- Mockups must not introduce unverifiable claims or private information.

## Required Notes

Every approved mockup should document:

- Screen goal.
- Source tool.
- Prompt.
- Accepted decisions.
- Rejected decisions.
- Accessibility notes.
- Responsive notes.
- Implementation risks.

## Rejection Criteria

- Depends on hover-only content.
- Requires unreadable tiny text.
- Uses impossible layout behavior for responsive HTML.
- Has weak contrast or unclear focus states.
- Looks generic or unrelated to the portfolio direction.
- Overuses decorative AI effects instead of communicating Sergio's profile.
